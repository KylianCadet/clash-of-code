## Mode
Fastest mode

## Goal
You are given an integer P number of players.
Each player has C cards.
For each player, compute the sum of the value of their cards, then output the maximum of these sums.

## Input
Line 1: Two integers, P and C separated by a space
Next P lines: each line contains the values of the cards held by one player separated by a space

## Output
Line 1: One integer, the maximum sum among all players

## Constraint
1 ≤ P ≤ 10
1 ≤ C < 20
0 ≤ value of each card ≤ 50
