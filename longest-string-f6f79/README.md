## Mode
Fastest mode

## Goal
Given several strings, find the one with the greatest length.

If multiple strings share the same maximum length, you must output the first one among them.

## Input
Line 1: An integer N — the number of strings.
Next N lines: Each line contains a non-empty string S (may contain spaces).

## Output
Line 1: The longest string among the N given strings. If several strings have the same maximum length, output the first one that reaches this length.

## Constraint
1 ≤ N ≤ 10
1 ≤ length of S ≤ 20
