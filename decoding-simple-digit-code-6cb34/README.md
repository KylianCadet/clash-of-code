## Mode
Fastest mode

## Goal
Mirko figured out that multiplying any digit by it's ASCII code results in an unique number. Your job is to decode Mirko's numbers. For example: for a digit 3 it's ASCII code is 51, so the encoded digit 3 would be 3 \* 51 \= 153.

## Input
Line 1: Single line containing space-separated encoded digits.

## Output
Line 1 : Decoded number.
