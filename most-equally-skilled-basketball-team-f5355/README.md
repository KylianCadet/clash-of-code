## Mode
Fastest mode

## Goal
You would like to construct a basketball team consisting of the most equally skilled players.

Given N players with skill-levels ranging from 0-99, pick 5 players, such that the difference between the most-skilled and least-skilled player is minimized.

## Input
Line 1: Number of players N
Next N lines: Skill level of a player

## Output
Line 1: Difference between most-skilled and least-skilled player in the chosen team

## Constraint
5 <\= N <\= 50
