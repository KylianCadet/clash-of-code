## Mode
Fastest mode

## Goal
Reduce the number to a single digit by repeatedly multiplying its digits. Then, determine the maximum value formed by inserting the resulting digit in either the first or the last position of the original number.

Example:
input:
999
1) 9\*9\*9\=729, then 7\*2\*9\=126, next 1\*2\*6\=12 and 1\*2\=2
2) maximum between 2999 and 9992
output:
9992

## Input
Line 1: A number number .

## Output
Line 1: An integer N

## Constraint
2 < number of digits in number <10
