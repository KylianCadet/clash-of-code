## Mode
Shortest mode

## Goal
You must output the number of trailing zeroes in factorial, in base P where P is a prime number.
As a remainder, the factorial of a non-negative integer N, N! is the product of all positive integers less than or equal to N.

Input:
Line 1: An positive integer N
Line 2: a prime integer P

Output:
Line 1: the number Z of trailing zeroes of N!, in base P

Constraints:
0 < N < 200
2 <\= P
P is a prime number

Example :
N \= 10, P \= 2
\=\> N! \= 110,111,010,111,100,000,000 (base P)
\=\> Z \= 8
