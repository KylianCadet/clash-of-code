## Mode
Shortest mode

## Goal
You must output 3 strings that draw a queue of n stick-men.
A stick-man should look like the following:


 o 
/|\
/ \

## Input
An integer n for the number of stick-men

## Output
• Stick-men must be separated by a single space;
• Trailing spaces should not be removed.

Line 1: A string of n stick-men heads
Line 2: A string of n stick-men arms and bodies
Line 3: A string of n stick-men legs

## Constraint
1 <\= n <\= 10
