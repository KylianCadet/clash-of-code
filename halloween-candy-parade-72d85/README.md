## Mode
Fastest mode

## Goal
There are a few towns in a magical country. It's Halloween next week, and the towns are gearing up for the Great Candy Parade!

Every house in each town gives out candies to the parade-goers. But there's a twist — each town has a special arithmetic candy rule!

Each house gives out candies following an arithmetic sequence:
The first house gives A candies, and each next house gives D more than the previous one.

## Input
Line 1: An integer H for the number of houses.

Line 2: An integer A is the candies at first house.

Line 3: An integer D is the common difference between the houses.

## Output
You need to calculate the total number of candies distributed in that town.

## Constraint
H, A ≥ 0

-10 ≤ D ≤ 1000
