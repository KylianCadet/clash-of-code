## Mode
Fastest mode

## Goal
Given a list of integers, determine if the sum of any two elements is 10

## Input
Line 1: A string s representing a list of spaces-separated integers

## Output
Line 1: the indices, in numerical order, of the two numbers which add up to 10
If there is no pair, then the output is NOPE

## Constraint
1<\=s.length()<\=256
Either 1 pair or no pair of numbers add up to 10
