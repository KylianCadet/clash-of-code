## Mode
Shortest mode

## Goal
I found my old Nokia 3310 !! Its keyboard has only 12 keys.
Using this phone, you have to press once the key 2 to write an A and you need to press twice the key 3 to write an E.
For each message, give the sequence of numbers to press to write it with this phone.

This is how my phone looks :

\#  \*  \#  0  \#     \#
\#  +  \#  \_  \#  \#  \#
\#     \#     \#     \#
\#\#\#\#\#\#\#\#\#\#\#\#\#\#\#\#\#\#\#


## Input
Line 1 : A message with capital letters and spaces to write.

## Output
Line 1 : The sequence of keys to press.

## Constraint
1 <\= length of message <\= 32
