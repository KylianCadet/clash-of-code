## Mode
Shortest mode

## Goal
Write a function that takes a string as input and returns the average ASCII code (rounded down) of all lowercase letters it contains.

## Input
Line 1: containing the string s.

## Output
The calculated average.
- If the average is decimal, it should be rounded down.
- If there is no lowercase letters, output must be 0.

## Constraint
1<\=length of s<\=60
s contains only letters.
