## Mode
Fastest mode

## Goal
A 10 space-separated integers, list t.
The t are sort by how many 1's in a binary number by decending.
When the number of 1's is the same, the integer with the smaller number is in front.

## Input
Line 1: A 10 space-separated integers t.

## Output
Line 1: Output an array t to descending sort by 1's count in a binary number.

## Constraint
A t.length is 10.
0 <\= t.value <\= 100
There aren't same number in the list t.
