## Mode
Fastest mode

## Goal
You have to find all the roots of polynomials. We give to you the polynomials in the form k(X-a)(X-b)...(X-d)etc. Ex: 3(X-1)(X+6)(X-200). In this example, the roots of the polynomials are 1, -6 and 200.

## Input
A line input\_str int the form k(X-a)(X-b)...(X-z).

## Output
All roots in one line in ascending order and separated by spaces.

## Constraint
All roots are integers.
