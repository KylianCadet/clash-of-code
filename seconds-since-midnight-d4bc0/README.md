## Mode
Fastest mode

## Goal
Given a date and time, your task is to calculate the total number of seconds that have passed since midnight (00:00:00) of the same day.

## Input
Line 1 A string representing a date and time in the format YYYY-MM-DD HH:MM:SS

## Output
Line 1 An integer representing the number of seconds passed since midnight (00:00:00) on the specified day.

## Constraint
The date and time format is guaranteed to be valid.
