## Mode
Shortest mode

## Goal
The sum of the unique digits (not numbers) in all the numbers.

## Input
Line 1: A single integer N, the number of numbers.
Next N lines: An integer X.

## Output
One integer: the sum of the unique digits in all numbers.

## Constraint
1 ≤ N ≤ 10
1 ≤ X ≤ 10^5
