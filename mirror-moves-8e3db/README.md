## Mode
Shortest mode

## Goal
A palindrome reads the same from left to right and from right to left.

You are given S, a string composed entirely of digits from 0 to 9. You can modify S by making moves.

Each move increases or decreases exactly one digit of S by 1. There is no carrying or borrowing, and every digit must remain between 0 and 9.

Output the minimum number of moves required to turn S into a palindrome.

## Input
Line 1: The digit string S.

## Output
Line 1: The minimum number of moves required to turn S into a palindrome.

## Constraint
1 ≤ number of digits in S ≤ 99
S contains only digits from 0 to 9.
S may start with 0.
