## Mode
Shortest mode

## Goal
Given a time, output the angles of the two hands.

## Input
Line 1: Time in hh:mm format.

## Output
Line 1: Angle of Hour hand.
Line 2: Angle of Minute hand.

## Constraint
Time is given in 24-hour format.
0/12 o'clock is 0°.
