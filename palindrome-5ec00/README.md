## Mode
Shortest mode

## Goal
You are given n strings, and you must return all the palindromes or None if there is no palindrome. A palindrome is a string of characters that reads the same forward and backward.

## Input
Line 1 : An integer n representing the number of strings.
n next lines : A string string.

## Output
Line 1 : all palindromes separate with a space in the order of their appearance or None if there is no palindrome.

## Constraint
1≤ n ≤ 10
1 ≤ length of string ≤ 100
string contains non-space characters only.
