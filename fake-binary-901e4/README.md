## Mode
Shortest mode

## Goal
Given a string of digits n, convert all digits below 5 to 0, and all digits greater than or equal to 5 to 1.

The concept for this clash originates from a kata on Codewars: https://www.codewars.com/kata/57eae65a4321032ce000002d

## Input
Line 1: A string n

## Output
Line 1: The result after converting n

## Constraint
1 <\= length of n <\= 100
